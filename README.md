# АКСИОМА / HackerMatrix

Адаптивный одностраничный сайт на Astro 5 и Tailwind CSS 4. Статическая сборка без серверных зависимостей, внешних шрифтов и аналитики. Логотипы взяты из вложений исходной беседы.

## Запуск

Требуется Node.js 22.12+.

```sh
npm ci
npm run dev
```

Локальный адрес: http://127.0.0.1:4321.

```sh
npm run check
npm run build
npm run preview
```

Готовый сайт — в `dist/`. Эту папку можно разместить на любом статическом хостинге. Для размещения в подпапке задайте `base` в конфигурации Astro и скорректируйте пути к изображениям.

## Содержание

В `src/data/content.ts` находятся название компании, реквизиты и три модуля. Основной текст страницы — в `src/pages/index.astro`. Визуальные стили и адаптация — в `src/styles/global.css`; Tailwind подключён через официальный Vite-плагин, цветовые токены доступны как utilities.

Описание продукта основано на предоставленных сведениях: разрабатываемая интерактивная веб-платформа для обучения и соревнований по информационной безопасности, индивидуальные образовательные траектории, обучение, редактор заданий и мониторинг прогресса. Сайт не заявляет о готовности продукта к эксплуатации.

Реквизиты, генеральный директор и фактический адрес заполнены по данным заказчика. Электронная почта добавлена под фактическим адресом. Юридический адрес не предоставлен и не выводится. Данные редактируются в `src/data/content.ts`.

## Форма заявки

Форма проверяет обязательные поля и формирует локальный UTF-8-файл `axioma-request.txt`. Данные не передаются на сервер, не сохраняются в localStorage, сообщение об успешной отправке отсутствует. После скачивания пользователь самостоятельно передаёт заявку по известному ему каналу связи.

Для реальной отправки нужно подключить обработчик и указать подтверждённые контакты. При этом следует обновить текст формы и сведения об обработке персональных данных в соответствии с фактическим процессом.

## Доступность и движение

Есть ссылка перехода к содержимому, подписи полей, семантическая навигация, клавиатурные состояния, доступное мобильное меню и нативные раскрывающиеся описания модулей. Движение отключается при `prefers-reduced-motion: reduce`. Без JavaScript содержание остаётся доступным, а форма объясняет необходимость включить JavaScript для скачивания.
